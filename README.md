# Учитель фортепиано (Android 8+, планшет)

USB-пианино (class-compliant MIDI) → планшет через OTG. Приложение принимает
нажатия клавиш (как `aseqdump`), показывает ноты и клавиатуру, учит по 3 режимам.

## Сборка
* **Android Studio**: File → Open → папка проекта → Run / Build APK.
* **Командная строка** (JDK 17 + Android SDK 34): `gradle assembleDebug`
  → `app/build/outputs/apk/debug/app-debug.apk`.
* **GitHub Actions**: залейте проект в репозиторий — `.github/workflows/build.yml`
  соберёт APK (Actions → Artifacts).

## Использование
1. Подключите пианино по USB (нужен OTG-кабель). Устройство появится в списке «MIDI».
2. «Открыть MIDI» — загрузить .mid (или MusicXML как самостоятельную пьесу).
3. «Аппликатура (pianoplayer)» — загрузить MusicXML (.xml/.musicxml/.mxl), который
   выдал pianoplayer, напр. `pianoplayer song.xml -o song_fingered.xml`.
   Пальцы накладываются на ноты MIDI по высоте и позиции в долях.
4. Режимы (кнопки на экране):
   * Слушай — пьеса проигрывается на пианино (MIDI OUT) либо на планшете.
   * Смотри — ноты + пальцы + подсветка клавиш, ждёт правильных нажатий.
   * Вспоминай — подсказки убраны, ждёт правильных нажатий.
   Аккорд засчитывается, когда все его клавиши зажаты одновременно и лишних зажато не больше
   `EXTRA_ALLOWED` (константа в MainActivity.kt, по умолчанию 1).
5. Позиция: тап по нотам, ползунок «Позиция» или «⏮ В начало».
6. Ноты: две строки — активная (светлая, с курсором) и следующая (тёмная).
   Нажатые клавиши рисуются на нотах в позиции курсора (зелёные / красные при ошибке).
7. «Картинка рук» — контур рук с подсвеченными пальцами.
8. Цвет: синий — правая рука, оранжевый — левая, зелёный — ваше нажатие, красный — ошибка.
